Importar lista de canales

Sube un archivo M3U o M3U8 con varios canales de una vez, en vez de añadirlos uno a uno con un enlace. También funciona con un archivo de texto simple con un enlace por línea.

Si la rellenas, todos los canales de este archivo entrarán con esa misma categoría (por ejemplo, el nombre del país), así se quedan agrupados juntos en la app aunque luego importes otros países. Si la dejas en blanco, se usa la categoría que ya traiga el propio archivo.
